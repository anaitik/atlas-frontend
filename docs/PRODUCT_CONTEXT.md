# Frontend Product Context

Atlas frontend is the operator and reviewer interface for ESG workflows.

## Frontend product responsibilities
- Guide users through collection, verification, and reporting flows.
- Present confidence and status clearly for reviewer decisions.
- Surface governance and audit information in understandable UI.

## Product priorities
- Fast onboarding for first-time users.
- Clear role-based workflow progression.
- Reliable UX for high-volume review operations.
